# VisionAssist

Assistive web app for visually impaired users: choose a photo of printed text, VisionAssist
recognises it in the browser (Tesseract.js) and reads it aloud (Web Speech API).

Course: DevSecOps Lab (CIAP Microproject) | SDG 9 and SDG 10

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8080` in this folder.
